    ROUTE COMPARISON

    三条路径，怎么判断？

    不做“名气排序”，只看培养方式、能力匹配和家庭承受度。

    FOCUS PLAN

    学军文渊自招 / 省招
    笔试与面试双线准备

    以能力迁移为核心：笔试看思考过程，面试看表达、反应和真实的学习兴趣。

    HIGH SCHOOL STRATEGY

    强基与三位一体，不是同一条赛道

    高中阶段再做最终选择，初中阶段先积累可迁移的学术能力和真实经历。

    强
    STRONG FOUNDATION

    强基计划

    更适合对基础学科有长期兴趣、学科优势突出、愿意接受本研衔接培养的学生。

    • 核心：高考成绩 + 高校考核
    • 现在：深耕一门优势学科，保住全科基础
    • 长期：竞赛思维、学术阅读、研究兴趣
    适配自问：我是否愿意多年研究一个基础问题？
    三
    TRINITY EVALUATION

    三位一体

    更适合学业稳定、综合素质有真实积累、表达与临场表现较好的浙江考生。

    • 核心：学业表现 + 综合测试 + 高考成绩
    • 现在：持续阅读、表达、社会观察与项目经历
    • 长期：材料整理、专业认知、面试表达
    适配自问：我能否用具体经历证明自己的能力？
